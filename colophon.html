My website is a ______.

This site is written by hand in HTML and CSS with no framework and no build step beyond a small script that fills the works table from a JSON file. The index follows the Prof. Dr. style: text, links, a table, and a “last updated” line. Each work lives in its own folder and may take any form. Old versions are never deleted.

References: Websitesite by Jisu Choi; “My website is a shifting house next to a river of knowledge” by Laurel Schwulst; mindyseu.com; Be Here Now by Ram Dass.

Typeface: Arial Narrow, or whatever condensed sans your computer has.

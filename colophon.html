Colophon

My website is a ______.

This site is written by hand in HTML and CSS with no framework and no build step beyond a small script that fills the index from a JSON file. The index is a manuscript with plates: a board that shows what state each thing is in, pictures where pictures belong, and a margin that says what I am doing now. It descends from the Prof. Dr. style: text, links, and a “last updated” line. Each work lives in its own folder and may take any form. Old versions are never deleted. Earlier shapes of this index are kept in explorations.

References: Websitesite by Jisu Choi; “My website is a shifting house next to a river of knowledge” by Laurel Schwulst; mindyseu.com; Be Here Now by Ram Dass.

Typeface: whatever sans your computer uses for its own interface. Nothing is downloaded. The site began in Times with a condensed sans for the margins; in September 2026 it moved to one sans throughout, so that the work pages and the index speak with one voice. The earlier shape is kept in explorations.

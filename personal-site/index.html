Five ways the personal site could feel.

Schematic page layouts for Home, Work, and About. Structure and hierarchy only — no final visual system yet. Pick a direction to poke around.

  • A
    Brand-first landing

    Editorial

    Full-bleed atmosphere plane. Name as the hero signal, one line, one CTA group. Work and about live below the fold.
  • B
    Index of work

    Archive

    Sidebar identity + filterable project table. Dense, tool-like, good if the site is mostly a record of experiments.
  • C
    Atelier / studio

    Split

    Fixed identity pane on the left; featured work on the right. Feels like a studio wall you keep returning to.
  • D
    Desktop of blocks

    Garden

    Three columns of small modules — notes, projects, links. More playground than brochure; easy to grow over time.
  • E
    Single column

    Signal

    One narrow stack: name → what you do → selected work → contact. Maximum clarity, minimum chrome.

How to read these

  • Dashed boxes are placeholders (images, media, unknown content).
  • Brown labels mark layout intent — not UI chrome.
  • Each direction includes Home, Work, and About wireframes, plus a rough mobile sketch.
  • Copy is stand-in; tone can shift once a direction is chosen.
